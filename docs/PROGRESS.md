# 진행 기록 · 2026-11-12

## 방향과 파일

- 기존 Godot/Python 전시와 분리한 HTML/CSS/JavaScript 버전 C.
- 사용자 승인 의례물형 캐릭터 시트 두 원본을 보존하고 정면 전신만 투명 WebP로 추출. 원본 해시와 추출 정보 기록. 외형 재디자인 없음.
- 실제 입력 → Worker 분석 → 착석 판정 → 연출을 분리. AI 결과 지연/카메라 유실은 자동 착석 중지. 수동 비상 연출을 자동 검증과 구분.
- Chrome 시작 버튼, 장치·해상도 선택, 화면 ROI 드래그, 착석 기준 저장, 관리자 설정/가리기, 설정·수치 로그 내보내기 구현.
- 두 귀신 시간차 .8초 공개, 등장·퇴장 보간, 입력 유실 유예, 지속 착석 중 중복 실행 방지, 빈 자리 재무장 구현.
- 로컬 Face/Pose 모델과 JS/WASM 포함. 런타임 외부 요청을 CSP로 제한. 서버는 loopback에서 읽기 요청만 처리.
