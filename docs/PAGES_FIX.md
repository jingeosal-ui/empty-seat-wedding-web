# GitHub Pages 404 수정 · 2026-11-14

사용자 다른 기기의 404 화면을 확인한 뒤 실제 GitHub 설정에서 Pages disabled / branch None을 발견했다. 앞선 실행 링크 안내는 배포 성공을 검증하지 않은 잘못된 안내였다.

## 수정

- 기존 공개 저장소를 유지하고 Pages source를 GitHub Actions로 활성화.
- public 디렉터리만 정적 사이트로 배포. 로컬 서버, 제작 원본, 개인 카메라 검증 자료는 사이트에서 제공하지 않는다.
- HTML 링크, Worker, SDK/WASM/모델, 영상 manifest와 포스터/영상 경로를 배포 접두사에 맞춰 해석. localhost 루트도 유지.
- 기존 승인 걷기/가리개 영상 4개와 포스터 2개 사용. 새 생성이나 외형 변경 없음.
- SDK 1.2.3과 모델 2종 및 WASM의 파일 크기/SHA-256 고정. CI만 공식 배포처에서 받아 검증하고 실제 실행은 동일 사이트 파일을 사용.
- 모델 경로/Worker 초기화 회귀 검사 3개를 기존 12개에 추가. 코드 검사 15개 통과. 실제 카메라 정확도와 별개.

## 현장 범위

다른 물리 PC의 카메라/권한/의자영역은 그 PC에서 설정 및 검증이 필요하다. 휴대폰 Safari의 영상 알파/착석 성능을 보장하지 않으며 전시 운영 대상은 데스크톱 Chrome이다. 사용자 카메라 영상을 업로드하지 않는다.

배포 및 브라우저 검증 결과는 후속 기록에 추가한다.
