# 현장 카메라 시험 안내

2026-11-12: 사용자는 지금 착석 시험이 어려워 추후 현장에서 진행하기로 했습니다. 내장 카메라 입력과 로컬 AI 분석 연결 확인을 실제 착석 정확도 검증으로 대신하지 않습니다.

## 처음 준비

1. 폴더 전체를 최종 PC에 복사합니다. Chrome과 Node.js 22 이상이 설치되어 있어야 합니다.
2. `START_EXHIBITION.cmd`를 더블클릭하고 서버 창을 열어 둡니다. Chrome에서 카메라 시작을 눌러 권한을 허용합니다.
3. 설정에서 카메라를 선택하고 ‘저장하고 카메라 다시 연결’을 누릅니다. 실제 영상과 ‘카메라 연결됨’을 확인합니다. 연결 오류라면 다른 카메라 사용 앱을 닫고 장치·권한·USB 연결부터 점검합니다.
4. 관객 정면에서 어깨·엉덩이·무릎·발목이 보이도록 카메라와 의자를 배치합니다. 밝기를 너무 낮추지 말고 관객 앞쪽에 은은한 조명을 둡니다.
5. ‘화면에서 의자 영역 그리기’를 눌러 **앉았을 때 엉덩이가 놓이는 부분**을 드래그합니다. 의자 전체나 화면 전체를 크게 잡지 않습니다.
6. 설정을 닫고 D키로 감지 정보를 켭니다. AI 분석 중인지, 결과 나이가 계속 갱신되는지 확인합니다.

## 착석이 잘 안 잡힐 때

- ‘의자 영역 밖’: 반전 화면의 엉덩이 위치와 영역을 다시 맞춥니다.
- ‘엉덩이·어깨가 충분히 보이지 않음’: 카메라 각도·거리·조명을 바꿉니다. 민감도만 높여 해결하려 하지 않습니다.
- ‘다리 굽힘 또는 착석 기준이 필요함’: 무릎과 발목이 보이는지 확인합니다. 불가능하면 실제로 앉은 상태에서 설정의 ‘지금 앉은 자세를 2초간 저장’을 사용하고 ‘무릎이 안 보일 때 저장된 착석 기준 허용’을 켭니다.
- 상체 기준 모드는 서 있는 사람이 같은 위치에 있을 때 혼동할 수 있습니다. 아래의 서 있기/통과 시험을 반드시 함께 합니다.
- ‘자세 안정화 중’: 카메라를 고정하고 움직임을 줄입니다. 안정성 허용 폭·착석 유지 시간을 조금씩 조절합니다.
- ‘AI 결과가 오래되어 판정 보류’: 분석 해상도를640에서480으로 낮춰 시험하거나 다른 무거운 앱을 종료합니다. 분석 목표는12FPS지만 실제 처리 속도는 기기마다 다릅니다.

카메라 종류·화면 비율·설치 각도·의자 위치가 바뀌면 영역과 착석 기준을 새로 맞춥니다. 설정을 가져왔더라도 새 장소에서 재확인합니다.

## 성능과 기록

모델 준비가 끝나고 ‘성능 측정 새로 시작’을 누릅니다. 최소3회차 동안 등장·가리개·퇴장 구간을 보면서 멈춤/깜빡임을 확인합니다. ‘검증 기록 저장’으로 수치 파일을 저장합니다. 화면FPS와 AI 분석시간을 따로 보고, 평균뿐 아니라 최대 프레임과50ms 초과도 확인합니다. 저장되는 수치 파일에는 카메라 설정이 들어갈 수 있으므로 외부 공유 전 장치 식별자를 제거합니다.

전시 운영 때는 설정과D 정보를 닫고 H로 운영 표시를 숨기고 F로 전체화면을 켭니다. 관객에게 일어나라고 요구하는 진행 안내는 표시하지 않습니다.

## 현재 아트 상태

가리개는 종이 레이어 시안으로 손·팔이 실제로 내리는 영상은 아직 없습니다. 현재 동작을 자연스러운 양손 실사 애니메이션으로 승인하지 않습니다. 얼굴/의상이 바뀌지 않는 투명 WebM으로 이 구간을 교체한 뒤 시작·끝 자세, 손, 얼굴, 반복과 전환을 별도로 검수해야 합니다.
