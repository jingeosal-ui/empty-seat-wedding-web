# 별도 설치 없는 Windows 실행본

`빈자리의혼례_웹캠_C_설치없이실행` 폴더는 실행 환경과 AI 모델을 함께 포함합니다. **대상 PC에 Node.js나 npm을 설치하지 않습니다.**

## 다른 PC에서

1. ZIP 파일을 옮긴 뒤 마우스 오른쪽 → 모두 압축 풀기를 사용합니다. ZIP 안에서 직접 실행하지 않습니다.
2. 풀린 폴더의 `00_전시시작.cmd`를 더블클릭합니다. `START_EXHIBITION.cmd`도 같은 실행기입니다.
3. Chrome에서 카메라 시작을 누르고 카메라 권한을 허용합니다.
4. 설정에서 실제 사용할 카메라와 의자 영역을 새로 지정합니다. 설치 위치가 바뀌었으므로 기존 보정값을 그대로 믿지 않습니다.
5. 자세한 시험은 `현장_카메라_시험안내.md`를 따릅니다.

실행 중 서버 창은 열어 둡니다. 종료는 그 창에서 Ctrl+C입니다. 실행 중 인터넷 연결은 필요 없습니다. Chrome은 별도로 설치되어 있어야 합니다. 기본 지원 대상은 **Windows x64(Intel/AMD 64비트)**입니다. ARM 전용 네이티브 실행 및32비트 Windows는 이번 배포 검증 대상이 아닙니다.

## 포함 내용과 출처

- `runtime/node-win-x64/node.exe`: 공식 Node.js v26.13.1 LTS 실행 파일. npm·설치 프로그램은 제외.
- 같은 폴더의 `LICENSE.txt`: 해당 버전 Node와 포함된 제3자 구성 요소의 라이선스 원문.
- `runtime.json`, `SHASUMS256.txt`: 버전·공식 다운로드 주소·SHA-256 출처.
- `public/models`, `public/vendor`: 로컬 MediaPipe 모델과 실행 라이브러리.

공식 출처: https://nodejs.org/dist/v26.13.1/ 와 https://github.com/nodejs/node/blob/v26.13.1/LICENSE

시작 파일은 시스템의 `node` 명령이나 PATH를 검색하지 않고 동봉된 실행 파일을 직접 지정합니다. 시스템 설정이나 Node 설치 상태를 바꾸지 않습니다. 런타임은 로컬 파일 제공에만 사용하고 브라우저에 실행 파일 자체를 제공하지 않습니다.

## 제작 재현

소스 저장소를 받은 제작자는 Node를 사용할 수 있는 환경에서 `npm ci`, `npm run setup`, `npm run prepare-runtime`, `npm run package`를 실행합니다. 이 준비 과정에는 최초 다운로드가 필요합니다. 배포받는 전시자는 이 명령을 실행하지 않습니다. 이 실행 파일은 Git 소스에 중복 업로드하지 않고 공식 주소와 고정 체크섬으로 재현합니다.

## 검증 범위

검증 수치는 `portable-validation.json`에 기록합니다. 시스템 Node가 PATH에 없는 환경에서 동봉된 실행기와 실제 HTTP 리소스 제공을 확인합니다. 이 시험은 다른 물리 PC에서의 카메라 정확도나 자연스러운 가리개 손/팔 연기의 검증을 대신하지 않습니다. 기존 가리개 레이어 시안과 실제 착석 미검증 상태는 유지됩니다.
