# 빈자리의 혼례 · 걷기와 얼굴 공개 V2

승인된 손각시·몽달귀신이 얼굴을 가린 채 실제 발걸음으로 접근하고, 관객 양옆에 멈춘 뒤 손각시 먼저/몽달0.8초 뒤에 두루마리를 내리는 Chrome 웹캠 시연본입니다. 이전 C 실행본과 제작 원본은 보존합니다.

## 실행

웹에서는 https://jingeosal-ui.github.io/empty-seat-wedding-web/ 를 Chrome에서 엽니다. GitHub 로그인이나 Node/Python 설치는 필요 없습니다. 카메라 시작 버튼을 누르고 권한을 허용한 뒤, 그 컴퓨터의 의자 위치를 설정하세요. 휴대폰에서 링크가 열리는 것과 Windows 전시/착석 검증은 별개이며 이 작품의 운영 대상은 데스크톱 Chrome입니다.

`카메라 없이 귀신 동작만 보기` 링크는 실제 영상 준비와 두 귀신의 걷기/가리개 내림을 카메라 없이 확인합니다. 실제 관객 감지 시험을 대신하지 않습니다. 모델/SDK는 배포 시 고정 SHA-256을 확인하여 사이트 안에 포함하며, 관객 카메라 입력은 외부 서버에 업로드하지 않습니다.

배포 폴더 전체를 복사하고 `00_전시시작.cmd`를 더블클릭합니다. Chrome이 필요하며 Node/npm/Python 설치는 필요 없습니다. 포함된 실행 파일이 이 PC에서만 접속되는 서버를 엽니다. 서버 창은 전시 중 유지합니다. 기본 주소는 `http://127.0.0.1:4173/`입니다.

카메라 시작 → 권한 허용 → 사용할 카메라 선택 → 의자 영역 지정 → 실제 착석/일어섬/지나감/빈 의자 반복 보정 순서로 준비합니다. 실제 프레임을 수신해야 연결됨이 표시됩니다. 카메라가 바뀌면 의자 영역을 다시 설정합니다. 무릎이 보이지 않을 때는 관리자 화면에서 착석 자세를 저장하고 상체 기준을 명시적으로 허용할 수 있습니다. 현장 시험 안내는 docs에 있습니다.

F:전체화면 / R:초기화 / D:감지·성능 / H:운영 표시 숨김 / Space:비상 수동. `01_동작만보기.cmd` 또는 `/film-review.html`은 카메라 없이 동작을 검수하는 별도 화면이며 실제 착석 시험과 구분합니다.

## 동작과 파일

- 실제 걷기와 양손 가리개 동작은 사전 제작한 투명 WebM4개로 재생합니다. 정지 이미지를 확대/옆이동하여 걷기를 흉내내지 않습니다.
- 원본24FPS를 제작 단계에서30FPS로 보간했습니다. 화면 rAF FPS와 영상 자체의 프레임은 다릅니다.
- 마지막 정지 자세0.4초를 다음 영상 첫 자세에 연결하고, 영상 완료를 확인한 뒤 상태를 진행합니다. 공개 동작을 역재생하지 않으며 완전히 투명한RESET에서만 처음으로 되돌립니다.
- 카메라/AI Worker/화면 애니메이션은 독립입니다. 실행 중 생성형 AI·인터넷·Godot·Python·유료 API는 사용하지 않습니다. 모델과 라이브러리가 배포 폴더 안에 있습니다. 카메라 사진·영상·얼굴 정보는 외부로 전송하거나 녹화하지 않습니다.
- `public`은 실행 코드, `public/assets/film`은 사용 영상/포스터, `art/walk_reveal_v2`는 개발 작업 폴더의 원본/중간 결과, `tools/media`는 제작 스크립트입니다. 배포본에는 무거운 제작 도구와 중간 영상을 제외합니다.

## 검증 범위

착석 유지·유실·퇴장·재무장·시차·상태 FPS·영상 종료 대기 코드 검사12개 통과. 네 영상 전체 알파 디코딩과 밝은/어두운 배경 검수를 진행했습니다. 실제 Chrome 최초90.44초/세회차는 모두 초기화까지 완료했으며, 평균 화면95.24FPS/p9916.8ms/최대66.5ms/50ms초과2회와 몽달 걷기 누락1프레임이 기록됐습니다.

첫 표시 사전 준비를 보완했으나 사용자 Esc 입력으로 후속 UI 검수가 중단됐습니다. 보완본 재검수와 실제 관객 착석/퇴장 반복 시험은 남아 있습니다. AI 영상의 얼굴/의복 재질에는 미세 변화가 남으며 고정 시점 영상입니다. 현장 전시 검증을 모두 완료했다고 주장하지 않습니다.

개발 환경에서만 Node가 필요합니다. `npm ci`, `npm test`, `npm run verify`로 검사합니다. 출처/라이선스는 docs와 licenses를 참고하세요. GitHub 원본 저장소와 새 비공개 웹 시연 사이트는 별도이며, 온라인 주소는 실제 게시 성공 후에 안내합니다.
